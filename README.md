# Byte.exe 🤖
### A Tiny Pixel Robot with a Big Imagination

Byte.exe is a retro pixel-art robot character created for the haX.baby
hackathon. Byte is a curious little inventor who loves experimenting
with emotions, creativity, and digital worlds.

## ✨ Features

- Animated pixel-art robot character
- Interactive mood controls
- Dynamic facial expressions
- Automatic blinking animation
- Mouse-tracking eyes
- Interactive terminal modal
- Easter eggs and playful interactions
- Retro cyberpunk-inspired design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore Byte's interactive features!
